# Матрица RACI

RACI используется для распределения ответственности участников команды: 
* **R (Responsible)** — исполнитель
* **A (Accountable)** — ответственный за конечный результат
* **C (Consulted)** — консультируемый
* **I (Informed)** — информируемый

| Задача | Лавренова А. | Максимов Е. | Маркелов Г. | Андрианов Е. | Панферова А. | Новиков Б. |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| Формирование команды | R | I | I | A | I | I |
| Организация коммуникации | I | I | I | A | R | I |
| Распределение ролей | C | C | C | A | R | C |
| Исследование предметной области | C | I | I | C | I | A/R |
| Работа с данными | A | R | I | I | C | C |
| Проектирование архитектуры | C | R | C | I | A | C |
| Разработка программной части | C | R | C | I | A | I |
| Тестирование системы | I | C | R | I | C | A |
| Подготовка отчета | R | C | C | A | C | C |
| Обсуждение результатов | C | C | R | A | C | C |
